# Cookies and Local Storage

## Description
This project demonstrates the use of cookies in web development. It includes a login form that stores user information in cookies and displays them.

## Files
- `0-index.html`: Basic HTML page with login form and cookie management

## Usage
Access the page via `http://localhost:8080/0-index.html` using a local server (e.g., Live Server in VSCode).

## Features
- Login form with firstname and email inputs
- Cookie storage functionality
- Cookie display functionality
